# Kometa Install Plan (Manitoba)

> **For agentic workers:** Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax.

**Goal:** Install Kometa (formerly Plex Meta Manager) on the Manitoba seedbox to manage Plex metadata, collections, overlays, and posters automatically using TMDb / Trakt / IMDb data sources.

**Architecture:** Python CLI tool driven by YAML config, run as a `systemd --user` *timer* (daily, low priority) — **not** a long-running daemon. Writes directly to Plex via API token (already in `secrets/plex.token`). No web UI, no nginx exposure. State lives in `~/.apps/kometa/`.

**Why Kometa:** Closest single-tool answer to "make my Plex library look curated" — adds collections (Marvel Phase 4, Best of 2025, Recently Added by Studio), per-poster overlays (4K / IMAX / runtime), and bulk metadata cleanup that's tedious to do by hand for a 1000+ item library.

**Non-goals:**
- Replacing Plex's built-in posters wholesale (Kometa supplements, doesn't replace).
- Real-time metadata updates (timer-based, ~daily).
- Per-user collections (Kometa is server-wide).
- Anime metadata reconciliation (covered separately by Plex's built-in TVDB agent — Hama is dead, see eval).

## Conventions

- `SSHM` = `ssh -o BatchMode=yes quadstronaut@seedbox.example.com`. Defined in `scripts/lib/ssh.sh`.
- All installs idempotent.
- **Pin versions.** Kometa 2.x — pin to the latest tagged release at install time (e.g. `v2.x.y`). The install script reads from `secrets/kometa.version`; if the secret doesn't exist, it queries the GitHub API for the latest release tag and pins it.
- All commits include `Co-Authored-By: Claude Opus 4.7`.

## Phase 32 — Kometa install

### Task 32.1: Pin version + capture TMDb key (operator pre-req)

- [ ] **Step 1: Operator obtains TMDb API key** at https://www.themoviedb.org/settings/api → save to `secrets/tmdb.api_key` locally:

```bash
echo "<key>" > secrets/tmdb.api_key
chmod 600 secrets/tmdb.api_key
```

- [ ] **Step 2: Pin Kometa version** — install script will resolve and pin on first run:

```bash
if ! secret_exists kometa.version; then
  TAG=$(curl -fsSL https://api.github.com/repos/Kometa-Team/Kometa/releases/latest | grep -oP '"tag_name":\s*"\K[^"]+')
  [ -n "$TAG" ] || die "could not resolve Kometa latest tag"
  secret_write kometa.version "$TAG"
fi
```

### Task 32.2: Clone + venv + dependencies

**Files:**
- Create: `scripts/configure/55-kometa-install.sh`

- [ ] **Step 1: Clone the pinned tag + create venv**

```bash
KVER=$(secret_read kometa.version)

sshm 'bash -s' <<EOF
set -euo pipefail
mkdir -p ~/.apps/kometa
cd ~/.apps/kometa
if [ ! -d kometa ]; then
  git clone --branch "$KVER" --depth 1 https://github.com/Kometa-Team/Kometa.git kometa
else
  cd kometa
  git fetch --tags --depth 1 origin "$KVER:refs/tags/$KVER" || true
  git checkout "$KVER"
  cd ..
fi

if [ ! -d venv ]; then
  python3 -m venv venv
fi
./venv/bin/pip install --upgrade pip wheel >/dev/null
./venv/bin/pip install --no-cache-dir -r kometa/requirements.txt >/dev/null

mkdir -p ~/.apps/kometa/config ~/.apps/kometa/logs ~/.apps/kometa/cache
EOF
```

- [ ] **Step 2: Drop empty metadata stubs**

```bash
sshm 'touch ~/.apps/kometa/config/metadata/movies.yml ~/.apps/kometa/config/metadata/shows.yml'
```

The operator fills these in Phase 33 — until then, Kometa just runs the `operations:` block (genre/rating/studio updates from TMDb) on every Plex item.

### Task 32.4: Smoke run (dry mode) before scheduling

- [ ] **Step 1: Run Kometa once in `--run` mode, capture exit code**

```bash
sshm 'cd ~/.apps/kometa && ./venv/bin/python kometa/kometa.py --config config/config.yml --run --no-missing 2>&1 | tee ~/.apps/kometa/logs/first-run.log | tail -40'
EXIT=$?
[ $EXIT -eq 0 ] || die "Kometa first run failed — see ~/.apps/kometa/logs/first-run.log"
```

A successful first run prints a "Kometa Finished Run" footer and exits 0. Common failures:
- TMDb 401 → `tmdb.apikey` wrong.
- Plex 401 → `plex.token` expired (re-run Phase 5 audit).
- Library name mismatch → `Movies` / `TV Shows` must match your actual Plex library names exactly.

### Task 32.5: User-systemd timer (daily 03:30)

**Files:**
- Service: `~/.config/systemd/user/kometa.service`
- Timer: `~/.config/systemd/user/kometa.timer`

- [ ] **Step 1: Service unit (oneshot)**

```bash
sshm "cat > ~/.config/systemd/user/kometa.service" <<'UNIT'
[Unit]
Description=Kometa metadata + collection run
After=network-online.target
Wants=network-online.target

[Service]
Type=oneshot
WorkingDirectory=%h/.apps/kometa
ExecStart=%h/.apps/kometa/venv/bin/python %h/.apps/kometa/kometa/kometa.py --config %h/.apps/kometa/config/config.yml --run
Nice=15
IOSchedulingClass=idle
StandardOutput=append:%h/.apps/kometa/logs/kometa.log
StandardError=append:%h/.apps/kometa/logs/kometa.err
UNIT
```

`Nice=15` + `IOSchedulingClass=idle` keep Kometa polite on the shared seedbox — it yields CPU and disk to anything else running.

- [ ] **Step 2: Timer unit**

```bash
sshm "cat > ~/.config/systemd/user/kometa.timer" <<'UNIT'
[Unit]
Description=Kometa daily run

[Timer]
OnCalendar=*-*-* 03:30:00
RandomizedDelaySec=900
Persistent=true
Unit=kometa.service

[Install]
WantedBy=timers.target
UNIT
sshm 'systemctl --user daemon-reload && systemctl --user enable --now kometa.timer'
```

03:30 + 15min jitter avoids hammering TMDb at the same minute as every other Kometa user. `Persistent=true` catches up a missed run if the seedbox was offline at 03:30.

- [ ] **Step 3: Verify timer scheduled**

```bash
sshm 'systemctl --user list-timers kometa.timer --no-pager' | grep -q kometa.timer || die "kometa.timer not scheduled"
```

## Phase 33 — Operator: collections + overlays + initial library cleanup

This phase is operator-driven YAML editing under `~/.apps/kometa/config/metadata/`. No scripts — the install in Phase 32 is fully automated; the *content* of the metadata is curation work.

### Task 33.1: Decide opt-in features

Kometa has hundreds of pre-built defaults. Pick the small set that matters for the Manitoba audience (boomers + country folk). Recommended opt-ins:

- [ ] **Collections by streaming service** (Netflix Originals, HBO Originals, Apple TV+) — viewers recognize these and reach for them
- [ ] **Collection by decade** (80s, 90s, 2000s) — boomer-friendly
- [ ] **Overlays:**
  - Resolution badge (1080p / 4K) — but per `feedback_no-4k-profiles.md`, the library is 1080p-capped, so 4K should be rare
  - Audio codec badge (Atmos / DTS-HD)
  - Runtime overlay
- [ ] **Skip:**
  - "Trending" / "Popular" overlays (visual noise)
  - "MPAA Rating" overlay (boomers don't care, country folk don't care)
  - "Anime"-specific defaults (separate library, separate metadata strategy)

### Task 33.2: Wire pre-built defaults

- [ ] **Step 1: Reference Kometa's `defaults/` repo** — see https://kometa.wiki/en/latest/defaults/guide/. Add to `config/metadata/movies.yml`:

```yaml
collections:
  Streaming Services:
    template: { name: streaming, sep_style: blue }
  Decades:
    template: { name: decade, sep_style: navy }

overlay_files:
  - default: resolution
  - default: audio_codec
  - default: runtimes
```

- [ ] **Step 2: Trigger one full run, watch the log**

```bash
sshm 'systemctl --user start kometa.service && journalctl --user -u kometa.service -f --no-pager' | head -200
```

First full run with overlays may take 30-60 min and download ~500 MB of poster artwork. Subsequent runs are minutes.

### Task 33.3: Operator vigilance week one

- [ ] Daily `journalctl --user -u kometa.service` review — look for `WARN`/`ERROR` lines.
- [ ] Plex Web UI spot-check — confirm collections appear in expected libraries and overlays render at full resolution.
- [ ] If a collection doesn't make sense for your taste — comment it out in YAML, don't argue with Kometa about it.

## Rollback per phase

| Phase | If broken |
|---|---|
| 32 (Install) | `systemctl --user disable --now kometa.timer kometa.service && rm -rf ~/.apps/kometa ~/.config/systemd/user/kometa.{service,timer} && systemctl --user daemon-reload`. Plex itself is untouched (Kometa writes via API but doesn't delete). |
| 33 (Metadata) | Kometa supports `clean_bundles: false` + `empty_trash: false` (set in our config) — Plex keeps the original metadata. To revert a single collection: delete its block in YAML, rerun Kometa, the orphaned collection disappears next run. To revert overlays library-wide: set `overlay_files: []` in the metadata file, rerun. |

**Rule:** Never let Kometa delete bundles or trash. Operator inspects manually if cleanup is needed.

## Cost summary

- **Kometa**: $0 (open source, MIT-adjacent).
- **TMDb**: $0 (free API tier — generous, but rate-limited; Kometa is well-behaved).
- **Trakt** (optional): $0 (free) — only worth wiring up if operator wants Trakt list imports.
- **Disk**: ~500 MB cache + asset directory growth scaling with library size.
- **CPU**: minutes/day at most, daily 03:30 + jitter.

## What this plan does NOT do

- **No automatic poster/artwork uploads** beyond what TMDb provides. For custom artwork, drop files into `~/.apps/kometa/config/assets/<library>/<title>/` and Kometa will pick them up.
- **No Trakt sync** by default — operator opts in via Phase 33.
- **No Plex Discover changes** — Kometa works on local libraries, not Plex's online discovery.
- **No backwards compat with PMM v1.x configs.** Kometa 2.x is a clean break; if you have an old PMM config from 5 years ago, it won't load — start fresh.
- **No interaction with Sonarr/Radarr.** Quality profile management is Recyclarr's job (separate plan).

### Hard rules (non-negotiable)

- **No 4K** anywhere — Recyclarr profiles, Kometa overlays, transcoder hints, request quotas. 1080p ceiling. (per `feedback_no-4k-profiles.md`)
- **Pin every version** — never `latest`, never `main`. Surface pinned versions in `versions.env` at repo root for the future updater. (per `feedback_pin-app-versions.md`)
- **Plex-primary** in all media-server config; Jellyfin gets parity only where the feature explicitly serves trial users. (per `project_plex-primary-jellyfin-trial.md`)
- **Reuse `secrets/htpasswd.password`** for any new admin-facing self-hosted app. (per `feedback_shared-admin-password.md`)
- **Read ports from `~/.apps/nginx/proxy.d/<app>.conf`** at runtime, not config.xml. (per `project_manitoba-network-model.md`)
- **Continuous execution** — no per-phase approval. Pause only on missing creds, smoke failure, or blocking log errors. (per `feedback_continuous-execution-preferred.md`)
- **Browser is last resort** — CLI/API everywhere; defer manual browser steps to `docs/operator-deferred.md`; Playwright authorized only when no alternative exists.
- **Modern AI-augmented preferred** when there's a choice; willing to fork if upstream stalls. (per `feedback_modern-ai-augmented-apps.md`)

### Failure modes to avoid (this plan)

- **Never enable `empty_trash: true` or `clean_bundles: true`** — both can permanently delete Plex metadata. Our config sets them `false`; don't flip.
- **Never run a 4K-resolution overlay** — defaults must be 1080p-only. The library is 1080p-capped per `feedback_no-4k-profiles.md`; 4K overlays would be visual noise + policy drift.
- **Never `--ignore-schedule`** without operator approval — this can spam TMDb at full library scope and trigger 429.
- **Don't add anime metadata YAML in v1** — anime defaults are noisier and need separate curation. Defer.
- **Don't run before TMDb key is in `secrets/`** — Kometa fails fast but the failure log is loud.
- Don't commit secrets — gitignored.
