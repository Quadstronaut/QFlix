# QFlix Random Error Audit (REA) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans (inline batch execution) — operator authorized autonomous iteration to zero errors and end-to-end test pass.

**Goal:** Single PowerShell 5.1 script `scripts/local-llm/qflix-rea.ps1` that, on Windows logon, fetches 7 seedbox log surfaces in one SSH call, feeds the blob to every code-capable Ollama model installed locally (sequential), and posts a consensus Discord message on findings (with dead-man switch if Ollama itself is down).

**Architecture:** Phase 0 pre-flight gates (lock, tunnel-port-ready, Ollama health, model discovery, secrets), Phase 1 single SSH heredoc dumps JSON to `%APPDATA%\qflix-rea\last-fetch.log`, Phase 2 sequential model loop via Ollama `/api/generate`, Phase 3 consensus by signature → one Discord embed (error/heartbeat/dead-man). Failure modes silent-by-default; Ollama-down is the one exception (the dead-man).

**Tech Stack:** PowerShell 5.1, OpenSSH `ssh.exe`, Ollama HTTP API (`http://localhost:11434`), Discord webhook, sqlite3 on remote, COM ScheduledTasks API. Tests use plain pwsh assertion helpers (no Pester dep).

**Spec:** `docs/superpowers/specs/2026-05-11-qflix-rea-design.md`

**Branch:** `feat/qflix-rea` (already created; spec committed at sha `b588dc1`).

## Function Inventory (inside `qflix-rea.ps1`)

Every function is internal to the script. Param block at top supports `-Install`, `-Uninstall`, `-DryRun`, `-Once`, `-FixturePath <path>`.

| Function | Returns | Responsibility |
|---|---|---|
| `Get-RepoRoot` | string | Locate repo root (script's grandparent) to resolve `secrets/` |
| `Get-StateDir` | string | `$env:APPDATA\qflix-rea\` (created if absent) |
| `Read-State` | hashtable | Load `state.json` or return defaults |
| `Write-State` | void | Persist hashtable to `state.json` (atomic via tempfile rename) |
| `Acquire-Lock` | filestream | Open exclusive `state.json.lock`; null on already-locked |
| `Write-AuditLog` | void | Append one line; rotate at 10MB |
| `Get-CodeModels` | string[] | Run `ollama list`, filter by include/exclude regex |
| `Wait-ForTunnel` | bool | Poll `Test-NetConnection 127.0.0.1:42014` up to 120s |
| `Test-OllamaHealth` | bool | `Invoke-RestMethod http://localhost:11434/api/tags` |
| `Get-RemoteHeredoc` | string | Builds the bash heredoc emitted to seedbox (base64-safe section encoding) |
| `Invoke-RemoteFetch` | string | Run ssh.exe with heredoc; capture stdout; 60s hard timeout |
| `Invoke-Model` | object | POST to /api/generate; 240s hard timeout; return parsed array or null |
| `Extract-JsonArray` | array | Robust JSON array extractor (first `[..]` block, validate) |
| `Get-Consensus` | object[] | Group findings by normalized signature; collapse |
| `New-DiscordErrorPayload` | hashtable | Build embed payload for error message |
| `New-DiscordHeartbeatPayload` | hashtable | Build embed payload for clean heartbeat |
| `New-DiscordDeadmanPayload` | hashtable | Build embed payload for Ollama-down |
| `Send-Discord` | bool | POST payload to webhook; return success |
| `Install-Task` | void | Register Task Scheduler task at `\Archangel\QFlix-LLM\` |
| `Uninstall-Task` | void | Remove task |
| `Invoke-Main` | int | Orchestrates phases 0→3; returns exit code |

Functions are dot-sourceable: main flow is guarded by `if ($MyInvocation.InvocationName -ne '.' -and -not $script:DotSourceMode) { exit (Invoke-Main) }` so tests can load the script with `. .\scripts\local-llm\qflix-rea.ps1` and call helpers directly.

```powershell
    param($Expected, $Actual, [string]$Name)
```

```powershell
[CmdletBinding()]
param(
    [switch]$Install,
    [switch]$Uninstall,
    [switch]$DryRun,
    [switch]$Once,
    [string]$FixturePath
)
Set-StrictMode -Version 2.0
$ErrorActionPreference = 'Stop'

# ---------- Configuration ----------
$Script:SshExe        = "$env:WINDIR\System32\OpenSSH\ssh.exe"
$Script:SshHost       = 'quadstronaut@seedbox.example.com'
$Script:OllamaBase    = 'http://localhost:11434'
$Script:TunnelProbePort = 42014
$Script:TunnelWaitSec   = 120
$Script:SshTimeoutSec   = 60
$Script:ModelTimeoutSec = 240
$Script:ModelIncludeRx  = '(?i)(coder|^qwen3(:|$))'
$Script:ModelExcludeRx  = '(?i)(-base|-vl|^bge|embed)'
$Script:SectionByteCap  = 16384
$Script:AuditLogMaxBytes = 10MB
$Script:TaskFolderPath  = '\Archangel\QFlix-LLM\'
$Script:TaskName        = 'QFlix Random Error Audit'

# ---------- State + paths ----------
function Get-RepoRoot {
    Split-Path -Parent (Split-Path -Parent $PSCommandPath)
}

function Get-StateDir {
    $d = Join-Path $env:APPDATA 'qflix-rea'
    if (-not (Test-Path $d)) { New-Item -ItemType Directory -Path $d -Force | Out-Null }
    return $d
}

function Read-State {
    $p = Join-Path (Get-StateDir) 'state.json'
    if (-not (Test-Path $p)) {
        return @{ last_heartbeat_date = ''; last_ollama_dead_ping = '' }
    }
    try {
        $raw = Get-Content -Raw -LiteralPath $p
        $obj = $raw | ConvertFrom-Json
        return @{
            last_heartbeat_date   = if ($obj.PSObject.Properties.Name -contains 'last_heartbeat_date')   { [string]$obj.last_heartbeat_date }   else { '' }
            last_ollama_dead_ping = if ($obj.PSObject.Properties.Name -contains 'last_ollama_dead_ping') { [string]$obj.last_ollama_dead_ping } else { '' }
        }
    } catch {
        return @{ last_heartbeat_date = ''; last_ollama_dead_ping = '' }
    }
}

function Write-State {
    param([hashtable]$State)
    $p   = Join-Path (Get-StateDir) 'state.json'
    $tmp = "$p.tmp"
    ($State | ConvertTo-Json -Depth 5) | Set-Content -LiteralPath $tmp -Encoding UTF8
    Move-Item -Force -LiteralPath $tmp -Destination $p
}

# ---------- Main entry guard ----------
function Invoke-Main { return 0 }   # placeholder; filled in Task 11

if (-not $script:DotSourceMode) {
    exit (Invoke-Main)
}
```

```powershell
function Acquire-Lock {
    $p = Join-Path (Get-StateDir) 'state.json.lock'
    try {
        $fs = [System.IO.File]::Open($p, 'OpenOrCreate', 'ReadWrite', 'None')

function Write-AuditLog {
    param([string]$Line)
    $p = Join-Path (Get-StateDir) 'audit.log'

    Add-Content -LiteralPath $p -Value "$stamp $Line" -Encoding UTF8
```

```powershell
function Filter-OllamaListOutput {
    param([string]$RawText)
    $lines = $RawText -split "`r?`n"
    $names = @()
    foreach ($line in $lines) {
        if (-not $line) { continue }
        if ($line -match '^\s*NAME\s') { continue }
        $first = ($line -split '\s+',2)[0]
        if (-not $first) { continue }
        if ($first -match $Script:ModelExcludeRx) { continue }
        if ($first -match $Script:ModelIncludeRx) { $names += $first }
    }
    return ,$names
}

function Get-CodeModels {
    try {
        $out = & ollama list 2>$null | Out-String
        return Filter-OllamaListOutput -RawText $out
    } catch { return ,@() }
}
```

```powershell
function Wait-ForTunnel {
    param([int]$Port = $Script:TunnelProbePort, [int]$MaxSec = $Script:TunnelWaitSec, [int]$PollSec = 5)
    $deadline = (Get-Date).AddSeconds($MaxSec)
    while ((Get-Date) -lt $deadline) {
        $c = New-Object Net.Sockets.TcpClient
        try {
            $t = $c.ConnectAsync('127.0.0.1', $Port)
            if ($t.Wait(1000) -and $c.Connected) { return $true }
        } catch {} finally { $c.Close() }
        Start-Sleep -Seconds $PollSec
    }
    return $false
}

    try {
        $r = Invoke-RestMethod -Uri "$Script:OllamaBase/api/tags" -TimeoutSec 5 -ErrorAction Stop
```

```powershell
function Get-RemoteHeredoc {
    # Build a single bash script that emits one JSON object on stdout.
    # Each section is captured to a tmpfile, truncated to SECTION_CAP bytes,
    # then base64-encoded. Final assembly is plain JSON with base64 string
    # values; PowerShell side decodes and re-encodes as needed.
    $cap = $Script:SectionByteCap
    $bash = @"
#!/usr/bin/env bash
set -u
SECTION_CAP=$cap
TMP=`$(mktemp -d -t qflix-rea.XXXXXX)
trap 'rm -rf "`$TMP"' EXIT

collect() {
  local name="`$1"; shift
  # Run the command, capture combined stdout+stderr, truncate to SECTION_CAP bytes,
  # then base64 (one line, no wrap).
  ( "`$@" 2>&1 || true ) | head -c "`$SECTION_CAP" | base64 -w0 > "`$TMP/`$name"
}

# 1. *arr app logs (last 200 lines per file)
collect arr_logs bash -c '
  for app in sonarr sonarr2 radarr radarr2 prowlarr bazarr bazarr2; do
    for f in ~/.apps/`$app/logs/*.txt; do
      [ -f "`$f" ] && { echo "===== `$f ====="; tail -n 200 "`$f"; }
    done
  done
'

# 2. systemd --user journal errors (24h)
collect journal_errors bash -c 'journalctl --user -p err --since "24 hours ago" --no-pager 2>&1'

# 3. Cron mail spool (last 500 lines)
collect cron_mail bash -c 'tail -n 500 /var/spool/mail/quadstronaut 2>/dev/null || true'

# 4. Maint pipeline (state + 6h warnings)
collect maint_state bash -c '
  [ -f ~/.opt/maint/state.json ] && cat ~/.opt/maint/state.json
  echo "----- pusher warnings 6h -----"
  journalctl --user -u manitoba-maint-pusher --since "6h ago" -p warning --no-pager 2>&1 || true
'

# 5. nginx errors (last 200 lines)
collect nginx_errors bash -c 'tail -n 200 ~/.apps/nginx/logs/error.log 2>/dev/null || true'

# 6. Plex errors
collect plex_errors bash -c '
  grep -h "\[ERROR\]" ~/.apps/plex/Library/Application\ Support/Plex\ Media\ Server/Logs/*.log 2>/dev/null | tail -n 100 || true
'

# 7. Kuma red-state
collect kuma_red bash -c '
  sqlite3 -batch ~/.apps/uptimekuma/kuma.db "
    SELECT m.name FROM monitor m
    JOIN heartbeat h ON h.monitor_id = m.id
    WHERE h.time = (SELECT MAX(time) FROM heartbeat WHERE monitor_id = m.id)
      AND h.status = 0;
  " 2>/dev/null || true
'

# Assemble JSON. printf %s of base64 lines is safe (no quotes, no newlines).
printf '{'
printf '"fetched_at":"%s",' "`$(date -u +%Y-%m-%dT%H:%M:%SZ)"
printf '"host":"seedbox.example.com",'
printf '"sources":{'
sep=''
for k in arr_logs journal_errors cron_mail maint_state nginx_errors plex_errors kuma_red; do
  v=`$(cat "`$TMP/`$k" 2>/dev/null || echo '')
  printf '%s"%s":"%s"' "`$sep" "`$k" "`$v"
  sep=','
done
printf '}}'
printf '\n'
"@
    # Normalize CRLF → LF (bash hates CRLF)
    return ($bash -replace "`r", '')
}

function Invoke-RemoteFetch {
    param([string]$OutPath, [int]$TimeoutSec = $Script:SshTimeoutSec)
    $heredoc = Get-RemoteHeredoc
    $tmpInput  = [System.IO.Path]::GetTempFileName()
    $tmpOutput = [System.IO.Path]::GetTempFileName()
    $tmpErr    = [System.IO.Path]::GetTempFileName()
    try {
        # Write heredoc to a temp file; ssh.exe reads it via stdin.
        # IMPORTANT: write as UTF8 NO BOM and LF endings.
        $utf8 = New-Object System.Text.UTF8Encoding($false)
        [System.IO.File]::WriteAllText($tmpInput, $heredoc, $utf8)

        $sshArgs = @(
            '-o','BatchMode=yes',
            '-o','ServerAliveInterval=15',
            '-o','ServerAliveCountMax=2',
            '-o','StrictHostKeyChecking=accept-new',
            $Script:SshHost,
            'bash','-s'
        )
        $p = Start-Process -FilePath $Script:SshExe -ArgumentList $sshArgs `
                -RedirectStandardInput $tmpInput `
                -RedirectStandardOutput $tmpOutput `
                -RedirectStandardError $tmpErr `
                -NoNewWindow -PassThru
        $exited = $p.WaitForExit([int]($TimeoutSec * 1000))
        if (-not $exited) {
            try { $p.Kill() } catch {}
            throw "ssh fetch exceeded $TimeoutSec sec"
        }
        if ($p.ExitCode -ne 0) {
            $errText = Get-Content -Raw -LiteralPath $tmpErr -ErrorAction SilentlyContinue
            throw "ssh fetch exit $($p.ExitCode): $errText"
        }
        $blob = Get-Content -Raw -LiteralPath $tmpOutput
        if ($OutPath) { Set-Content -LiteralPath $OutPath -Value $blob -Encoding UTF8 -NoNewline }
        return $blob
    } finally {
        foreach ($f in @($tmpInput,$tmpOutput,$tmpErr)) {
            if (Test-Path $f) { Remove-Item -Force -LiteralPath $f -ErrorAction SilentlyContinue }
        }
    }
}
```

```powershell
function Extract-JsonArray {
    param([string]$Text)
    if (-not $Text) { return $null }
    # Find first '[' and walk to its matching ']' respecting strings.
    $i = $Text.IndexOf('[')
    if ($i -lt 0) { return $null }
    $depth = 0
    $inStr = $false
    $esc = $false
    for ($j = $i; $j -lt $Text.Length; $j++) {
        $ch = $Text[$j]
        if ($inStr) {
            if ($esc) { $esc = $false; continue }
            if ($ch -eq '\') { $esc = $true; continue }
            if ($ch -eq '"') { $inStr = $false }
            continue
        }
        if ($ch -eq '"') { $inStr = $true; continue }
        if ($ch -eq '[') { $depth++ }
        elseif ($ch -eq ']') {
            $depth--
            if ($depth -eq 0) {
                $candidate = $Text.Substring($i, $j - $i + 1)
                try {
                    $parsed = $candidate | ConvertFrom-Json
                    if ($parsed -is [array] -or $parsed -is [System.Object[]]) { return $parsed }
                    return ,@($parsed)
                } catch { return $null }
            }
        }
    }
    return $null
}

function ConvertFrom-FetchedBlob {
    param([string]$Json)
    # Decodes base64-encoded section values from the heredoc output.
    $obj = $Json | ConvertFrom-Json
    $decoded = @{}
    foreach ($prop in $obj.sources.PSObject.Properties) {
        try {
            $bytes = [Convert]::FromBase64String($prop.Value)
            $decoded[$prop.Name] = [System.Text.Encoding]::UTF8.GetString($bytes)
        } catch {
            $decoded[$prop.Name] = ''
        }
    }
    return [pscustomobject]@{
        fetched_at = $obj.fetched_at
        host       = $obj.host
        sources    = $decoded
    }
}
```

```powershell
function Get-Consensus {
    param([array]$Findings)
    $sevRank = @{ 'warning' = 1; 'error' = 2; 'critical' = 3 }
    $rankSev = @{ 1 = 'warning'; 2 = 'error'; 3 = 'critical' }
    $groups  = @{}
    foreach ($f in $Findings) {
        if (-not $f) { continue }
        $sig = ([string]$f.signature).Trim().ToLowerInvariant()
        if (-not $sig) { continue }
        if (-not $groups.ContainsKey($sig)) {
            $groups[$sig] = @{
                signature = $sig
                time = [string]$f.time
                app  = [string]$f.app
                file = [string]$f.file
                severity_rank = [int]($sevRank[[string]$f.severity] | ForEach-Object { if ($_) { $_ } else { 1 } })
                summary = [string]$f.summary
                excerpt = [string]$f.excerpt
                models_flagged = @([string]$f._model)
            }
        } else {
            $g = $groups[$sig]
            $r = [int]($sevRank[[string]$f.severity] | ForEach-Object { if ($_) { $_ } else { 1 } })
            if ($r -gt $g.severity_rank) { $g.severity_rank = $r }
            if (([string]$f.summary).Length -gt $g.summary.Length) { $g.summary = [string]$f.summary }
            if (([string]$f.excerpt).Length -gt $g.excerpt.Length) { $g.excerpt = [string]$f.excerpt }
            if ($f.time -and ($f.time -lt $g.time)) { $g.time = [string]$f.time }
            if ($f._model -and ($g.models_flagged -notcontains $f._model)) { $g.models_flagged += $f._model }
        }
    }
    $out = @()
    foreach ($k in $groups.Keys) {
        $g = $groups[$k]
        $g.severity = $rankSev[$g.severity_rank]
        $g.Remove('severity_rank') | Out-Null
        $out += [pscustomobject]$g
    }
    # Sort: severity desc, then time asc
    return $out | Sort-Object @{Expression={ $sevRank[$_.severity] }; Descending=$true}, time
}
```

```powershell
function Install-Task {
    $taskAction = "powershell.exe -NoProfile -WindowStyle Hidden -ExecutionPolicy Bypass -File `"$PSCommandPath`""
    # Use schtasks.exe for simplicity (works on every supported Windows; no module deps).
    $folderTaskName = $Script:TaskFolderPath.TrimEnd('\') + '\' + $Script:TaskName

    # schtasks doesn't let you create empty folders directly; creating a task at the path creates the folder.
    # First, delete any existing task at this exact path so we get a clean install.
    & schtasks /Delete /TN $folderTaskName /F 2>$null | Out-Null

    & schtasks /Create `
        /TN $folderTaskName `
        /SC ONLOGON `
        /RL LIMITED `
        /TR $taskAction `
        /F | Out-Null

    if ($LASTEXITCODE -ne 0) { throw "schtasks /Create failed (exit $LASTEXITCODE)" }

    # Apply additional settings that /Create can't set: StartWhenAvailable, ExecutionTimeLimit=PT15M,
    # AllowStartIfOnBatteries, MultipleInstancesPolicy=IgnoreNew. We use the Task Scheduler COM API.
    $svc = New-Object -ComObject 'Schedule.Service'
    $svc.Connect()
    $task = $svc.GetFolder($Script:TaskFolderPath.TrimEnd('\')).GetTask($Script:TaskName)
    $def = $task.Definition
    $def.Settings.StartWhenAvailable      = $true
    $def.Settings.DisallowStartIfOnBatteries = $false
    $def.Settings.StopIfGoingOnBatteries  = $false
    $def.Settings.ExecutionTimeLimit      = 'PT15M'
    $def.Settings.MultipleInstances       = 2   # 2 = IgnoreNew
    $def.Settings.RunOnlyIfNetworkAvailable = $true
    $svc.GetFolder($Script:TaskFolderPath.TrimEnd('\')).RegisterTaskDefinition(
        $Script:TaskName, $def, 6, $null, $null, 3, $null
    ) | Out-Null

    Write-Host "Installed task: $folderTaskName" -ForegroundColor Green
}

function Uninstall-Task {
    $folderTaskName = $Script:TaskFolderPath.TrimEnd('\') + '\' + $Script:TaskName
    & schtasks /Delete /TN $folderTaskName /F 2>$null | Out-Null
    Write-Host "Uninstalled task: $folderTaskName" -ForegroundColor Yellow
}
```

```powershell
}
```
